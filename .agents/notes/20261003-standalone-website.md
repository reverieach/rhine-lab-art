# 当前网站的独立源码仓库

Status: implemented

## 问题

用户要求公开仓库 open-active-theory，仅包含当前网站。原品牌原型依赖相邻 ActiveTheory 静态资源、分析目录中的构建基线、方案原图与 macOS 字体，直接复制无法在另一台机器构建。

## 决定

将本网站所需资源纳入 public，将构建基线收进 vendor/activetheory，将实际网站封面和字标矢量轮廓作为 src/assets 输入。保持原视觉模块与 UIL 参数，移除运行包旧接口凭证字面量；服务器只读取本仓库文件，不读取相邻项目。测试自行启动随机端口并关闭。

## 取舍

没有保留全工作区或通过外部下载脚本恢复全部历史素材，因为用户限定只上传当前网站。没有重写成新框架，以保留已完成的原动效机制。保留原网站场景资源和音乐，因此仓库包含必要二进制素材，第三方来源在 THIRD_PARTY_NOTICES.md 说明。

## 验证

npm run build 校验核心视觉模块与参数；npm test 检查服务及桌面/手机六场景、交互和媒体。浏览器截图、报告放在 .artifacts，不进入源码仓库。真实手机、用户视觉确认与正式录屏不由工程检查替代。
